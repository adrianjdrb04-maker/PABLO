# PABLO · servidor multijugador

Probar en tu ordenador:
  npm install
  npm start        (abre http://localhost:3000)

Publicar para tus amigos (gratis, Render.com):
  1. Sube esta carpeta a un repositorio de GitHub.
  2. En render.com: New > Web Service > elige el repositorio.
  3. Build command: npm install   ·   Start command: npm start
  4. Cuando termine, Render te da una URL. Pásala a tus amigos.
  Nota: en el plan gratuito el servidor se duerme tras un rato sin uso; la primera visita tarda ~30 s en despertar.
